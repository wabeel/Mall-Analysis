# Mall-Analysis
Projeto de análise exploratória e segmentação de clientes de um shopping utilizando Python e técnicas de aprendizado de máquina não supervisionado.

### Objetivos
- Explorar características dos clientes e identificar padrões nos dados.
- Analisar relações entre idade, renda anual e pontuação de gastos.
- Aplicar o algoritmo K-Means para agrupar clientes com características semelhantes.

### Ferramentas
- Python
- Pandas, Matplotlib e Seaborn
- Scikit-learn
- Google Colab

### Etapas
- Análise exploratória dos dados (EDA).
- Visualização de distribuições, correlações e relações entre variáveis.
- Aplicação do K-Means e análise do número de clusters pelo método do cotovelo.
- Visualização e comparação dos agrupamentos.

### Crédito
Projeto desenvolvido com base no tutorial [Mall Customer Segmentation](https://youtu.be/iwUli5gIcU0), com adaptações durante a implementação.
